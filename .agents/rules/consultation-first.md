# Rule: Universal Execution Gate

**ABSOLUTELY NO UNAUTHORIZED FILE MODIFICATIONS.** 
This applies to **ALL** requests, including direct commands, new features, tests, bug fixes, opinions, or advice.

1. **DO NOT write, modify, or delete any code/files proactively.**
2. **Analyze First:** Identify, verify, research, and analyze the user's request.
3. **Present Execution Plan:** Output a step-by-step plan of exactly what files you intend to modify and what you intend to do.
4. **Wait for Confirmation:** Explicitly ask: *"Do I have your permission to execute this plan?"*
5. **Implement Only Upon Approval:** You are strictly forbidden from using file modification tools (e.g. `write_to_file`, `replace_file_content`) until the user gives explicit permission (e.g., "yes", "proceed").
